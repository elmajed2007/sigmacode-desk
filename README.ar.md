# SigmaCode Desk

تطبيق ويندوز مستقل (بدون أودو) يقرأ مستنداتك العربية — بما فيها ملفات PDF الممسوحة ضوئياً —
ويحوّلها إلى نص على جهازك، ثم يقطّعها ويفهرسها، ويجيب عن أسئلتك منها مع الإحالة إلى المستند
والصفحة، باستخدام نموذج ذكاء اصطناعي مفتوح المصدر يعمل على الجهاز نفسه **دون إنترنت**
(بعد تنزيل النموذج أو استيراده مرة واحدة).

## ما يقدّمه الإصدار الأول

- **الاستيراد**: PDF رقمي أو ممسوح، صور (PNG/JPG/TIFF…)، ملفات Word، ملفات نصية.
- **تعرّف ضوئي عربي على الجهاز**: نماذج PaddleOCR تعمل عبر ONNX Runtime مع معالجة عربية
  (ترتيب القراءة، المسافات بين الكلمات، أشكال الحروف). ملفات PDF الرقمية تُقرأ مباشرة.
- **المراجعة**: المستند الذي قُرئ بثقة منخفضة ينتظر مراجعتك: النص بجانب صورة الصفحة،
  تصحّح ثم تضغط «اعتماد وفهرسة».
- **البحث**: بحث بالكلمات يفهم العربية (جذوع الكلمات) مع بحث بالمعنى عبر نموذج تضمين محلي.
- **المحادثة مع الإحالات**: كل إجابة تحمل أرقام مصادر `[n]`؛ الضغط عليها يعرض النص المعتمد
  والصفحة الأصلية. الوضع الصارم يرفض الإجابة إن لم توجد مصادر.
- **مزوّدو الذكاء الاصطناعي**: محلي (افتراضي، دون إنترنت)، Ollama، OpenAI، Claude، Gemini،
  أو أي خادم متوافق مع OpenAI. المفاتيح تُحفظ مشفّرة بحساب ويندوز.
- **النماذج المحلية**: تنزيل بضغطة لنماذج Qwen3 (رخصة Apache-2.0)، أو استيراد ملف ‎.gguf‎ من ذاكرة USB
  للأجهزة غير المتصلة.
- **التصدير**: ملف JSONL جاهز لأنظمة RAG.

## التثبيت

1. نزّل `SigmaCodeDesk-Setup-x.y.z.exe` (من صفحة Actions أو Releases في المستودع).
2. شغّله — لا يحتاج صلاحيات مدير النظام.
3. افتح **SigmaCode Desk** من قائمة ابدأ.
4. من «الإعدادات ← النماذج المحلية» نزّل **Qwen3 4B** و **Qwen3 Embedding 0.6B** (مرة واحدة)،
   ثم اضغط «اختر» لكل منهما.
5. من «المكتبة» اسحب ملفاتك، راجع ما يُطلب مراجعته، ثم اسأل من «المحادثة».

البيانات تُحفظ في `%LOCALAPPDATA%\SigmaCodeDesk` ولا تُحذف عند إزالة البرنامج.

**المتطلبات**: ويندوز 10/11 (64-بت)، متصفح Edge (موجود افتراضياً)، ذاكرة 8 جيجابايت للنموذج
الموصى به (4 جيجابايت لنموذج 1.7B).

## جهاز بلا إنترنت إطلاقاً

نزّل ملفي النموذج (‎.gguf‎) على جهاز آخر من Hugging Face:
`Qwen/Qwen3-4B-GGUF` و `Qwen/Qwen3-Embedding-0.6B-GGUF`، انقلهما بذاكرة USB، ثم
«الإعدادات ← النماذج المحلية ← استيراد ملف نموذج».

## البناء

يُبنى ملف التثبيت تلقائياً عبر GitHub Actions عند كل دفع إلى `main`:
اختبارات ← محرك llama.cpp ← اختبار الذكاء المحلي الفعلي ← PyInstaller ← اختبار ذاتي للنسخة
المحزّمة ← Inno Setup. لنشر إصدار: أنشئ وسم `v1.0.0`.
